# Установка WireGuard Easy (wg-easy) через Docker

Краткая инструкция по развёртыванию [wg-easy](https://github.com/wg-easy/wg-easy) — веб-интерфейса для управления WireGuard VPN — с помощью Docker.

## Требования

- Сервер с Linux (VPS/VM), доступ по SSH с правами `sudo`/`root`.
- Внешний (WAN) IP-адрес или Dynamic DNS-имя сервера.
- Открытые порты:
  - `51820/udp` — WireGuard;
  - `51821/tcp` — веб-интерфейс wg-easy.

---

## 1. Установка Docker

Если Docker ещё не установлен, выполните:

```bash
curl -sSL https://get.docker.com | sh
sudo usermod -aG docker $(whoami)
exit
```

После выхода **войдите в систему заново**, чтобы изменения групп применились.

---

## 2. Запуск wg-easy

Для автоматической установки и запуска wg-easy выполните:

```bash
docker run -d \
  --name=wg-easy \
  -e WG_HOST=🚨YOUR_SERVER_IP \
  -e PASSWORD=🚨YOUR_ADMIN_PASSWORD \
  -v ~/.wg-easy:/etc/wireguard \
  -p 51820:51820/udp \
  -p 51821:51821/tcp \
  --cap-add=NET_ADMIN \
  --cap-add=SYS_MODULE \
  --sysctl="net.ipv4.conf.all.src_valid_mark=1" \
  --sysctl="net.ipv4.ip_forward=1" \
  --restart unless-stopped \
  weejewel/wg-easy
```

> 💡 Замените `YOUR_SERVER_IP` на ваш WAN IP или Dynamic DNS hostname.
>
> 💡 Замените `YOUR_ADMIN_PASSWORD` на пароль для входа в веб-интерфейс.

После запуска:

- Веб-интерфейс доступен по адресу: `http://0.0.0.0:51821`.
- Конфигурационные файлы сохраняются в `~/.wg-easy`.

## Параметры (переменные окружения)

Параметры задаются через `-e KEY="VALUE"` в команде `docker run`.

| Env | По умолчанию | Пример | Описание |
|---|---|---|---|
| `PASSWORD` | — | `foobar123` | При установке требуется пароль при входе в веб-интерфейс. |
| `WG_HOST` | — | `vpn.myserver.com` | Публичный hostname вашего VPN-сервера. |
| `WG_PORT` | `51820` | `12345` | Публичный UDP-порт VPN-сервера. WireGuard внутри контейнера всегда слушает `51820`. |
| `WG_MTU` | `null` | `1420` | MTU, используемый клиентами. Сервер использует стандартный MTU WireGuard. |
| `WG_PERSISTENT_KEEPALIVE` | `0` | `25` | Значение в секундах для удержания «соединения» открытым. |
| `WG_DEFAULT_ADDRESS` | `10.8.0.x` | `10.6.0.x` | Диапазон IP-адресов клиентов. |
| `WG_DEFAULT_DNS` | `1.1.1.1` | `8.8.8.8, 8.8.4.4` | DNS-сервер, который будут использовать клиенты. |
| `WG_ALLOWED_IPS` | `0.0.0.0/0, ::/0` | `192.168.15.0/24, 10.0.1.0/24` | Allowed IPs, которые будут использовать клиенты. |
| `WG_POST_UP` | `...` | `iptables ...` | См. `config.js` для значения по умолчанию. |
| `WG_POST_DOWN` | `...` | `iptables ...` | См. `config.js` для значения по умолчанию. |

> ⚠️ Если вы меняете `WG_PORT`, обязательно измените и опубликованный порт в `-p`.

## Обновление

Чтобы обновиться до последней версии:

```bash
docker stop wg-easy
docker rm wg-easy
docker pull weejewel/wg-easy
```

Затем снова выполните команду `docker run -d \ ...` из [раздела 2](#2-запуск-wg-easy).

---

## Примечания

- Конфигурация и ключи хранятся в `~/.wg-easy` — сделайте резервную копию каталога перед обновлением.
- Веб-интерфейс по умолчанию слушает `51821/tcp`. Если сервер доступен из интернета, рекомендуется ограничить доступ к нему (файрвол/ reverse-proxy с TLS).
- Для работы WireGuard контейнеру требуются `NET_ADMIN`, `SYS_MODULE` и включённый `ip_forward` — они уже указаны в команде запуска.
- Порт `51820/udp` должен быть открыт на файрволе сервера/облачной панели.
