### Почему это сильный ход

Любой технический руководитель, открыв ваш GitHub, увидит не «студента, который прошел один курс», а **инженера, который систематизирует свой опыт**. Наличие файлов вида `название-задачи.md` говорит о том, что вы:
1. Умеете писать документацию (Runbooks / Playbooks).
2. Понимаете, как строить сеть (`wg-easy`, `cisco`).
3. Владеете разными подходами к мониторингу (`zabbix` vs `prometheus`).
4. Умеете работать с контейнерами и оркестратором (`docker`, `k3s`).
